# Домашний проект на летней практике ВШЭ по миникурсу "Микросервисное взаимодействие"

## Идея
Три микросервиса, реализующие возможности кикшеринговых сервисов(аренда самокатов, скейтбордов, возможно каршеринга).

### Микросервис № 1: Wallet

Реализованы основные функции кошелька. 
- У каждого пользователя ригинальный юзернейм!
- GET: Узнать всю информацию о пользователе по юзернейму (баланс, в ban'е ли пользователь(флажок истенен, если баланс отрицательный).
- GET: Узнать баланс пользователя по юзернейму.
- GET: Узнать в бане ли пользователь по юзернейму.
- POST: Зарегистрировать нового пользователя по юзернейму username и балансом balance. balance >= 0. Изначально пользователь не в бане.
- POST: Добавить деньги пользователю по юзернему.
- POST: Удалить деньги пользователю по юзернейму.


### Микросервис № 2: Skateboards

Реализованы основные функции базы данных о скейтах. 
- У каждого скейтборда оригинальный номер(как будто государственный, как у автомобилей)!
- GET: Узнать всю информацию о скейте по номеру (модель, цвет, свободен ли в данный момент скейт, номер вендингого автомата).
- POST: Зарегистрировать новый скейт по номеру number и необязательными параметрами: модель, цвет, номер автомата.
- POST: Пометить, что скейт занят.
- POST: Пометить, что скейт свободен.


### Микросервис № 3: Rent

Реализованы основные функции старта и окончания аренды скейта. 
- У каждого пользователя может быть максимум один скейт. У каждого скейта максимум один арендатор в один момент.
- GET: Узнать всю информацию о текущей аренде по юзернейму (номер скейта, дата и время начала аренды).
- GET: Узнать всю информацию о текущей аренде по номеру скейта (юзернейм, дата и время начала аренды).
- POST: Добавить новую аренду. Сделать соотвествуюшие пометки в других микросервисах.
- POST: Завершить аренду. Сделать соотвествуюшие пометки в других микросервисах.



## Использованные технологии.
- FastAPI
- PostgreSQL
- Docker и docker-compose
- Git
